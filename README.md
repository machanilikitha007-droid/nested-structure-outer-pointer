# Nested Structure with Pointer to Outer Structure

## Author
M.Likitha

## Description
This program demonstrates accessing a nested structure
through a pointer to the outer structure.

The Person structure contains an Address structure.
A pointer to Person is used to access both the outer
and nested structure members.

## Concepts Used
- Structure
- Nested structure
- Pointer to structure
- Arrow operator (->)
- Nested member access

## How to Run

gcc nested_structure_outer_pointer.c -o nested_structure_outer_pointer

./nested_structure_outer_pointer
